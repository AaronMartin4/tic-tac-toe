# Tic-Tac-Toe

A responsive, neon-styled Tic-Tac-Toe game against the computer, built with
plain HTML, CSS, and JavaScript.

## Play

Open `index.html` in a web browser. You play as X; the computer plays as O.
Start another round or reset the scoreboard with the on-screen controls.

## Features

- Responsive layout
- Computer opponent that takes winning moves and blocks yours
- Round and score tracking
- Accessible board labels and live game status

No dependencies or build step are required.
